FormFair — demonstration interface

This is a demonstration, not the study. It runs the FormFair library on markup you supply so the rules can be seen working. It is not part of the evaluation instrument, it contributes to no accuracy figure, and the examples are synthetic — none is drawn from the held-out evaluation corpus. Everything runs in this page: nothing is uploaded, nothing is stored, and it works with no network connection.


FormFair reports only what declared markup can support. A finding is a constraint observed in the markup, not a judgement about an organisation, and the absence of a finding is not a guarantee that a form accepts every name.
